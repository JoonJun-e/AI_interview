민지선님의 인터뷰 답변 전체
======================================================================

질문 1:
네, 안녕하십니까. 저는 연세대학교에서 교육학과와 응용통계학을 학습하고 있는 민지선입니다. 저는 교환학생 시절 UCLA에서 개최된 데이터 분석대회에서 팀장으로서 학습 데이터를 분석하여 80팀 중 1등을 하는 성과를 거두었습니다. 이후 해당 연구팀에서 인턴 제의를 받았습니다. 또한 병원 의료정보 제공 플랫폼 모두딱에서 인턴으로 근무를 하며 특과 전 세일지를 진행해 월 7천만 원의 매출을 달성하였습니다. 그리고 제가 가진 이러한, 그리고 저는 또한 데이터 분석 역량과 커뮤니케이션 역량을 가지고 있는데 저의 역량과 저의 경험을 활용을 하여서 해당 팀에서 좋은 결과를 낼 수 있습니다.

----------------------------------------------------------------------

질문 2:
우선 저는 해당 프로젝트의 리스크를 우선 분석할 것 같습니다. 만약에 리스크가 새로운 도전을 통해서 얻는 베네피드에 비해서 훨씬 크다면 저는 새로운 것을 원하는 팀원에게 설명을 할 것 같습니다. 왜냐하면 리스크가 크게 되면 저희가 새로 해서 얻을 것보다 이를 게 더 많아지기 때문에 그리고 또 회사의 일의 경우 리스크가 많다는 것은 정말 크게 문제가 생길 수도 있습니다. 따라서 새로운 것을 원하는 팀원에게 현재 리스크에 대해서 명확하게 분석을 한 것을 설명을 해주면서 해당 리스크가 왜 중요하고 왜 기존 방법을 통해서 안정적으로 해야 되는지를 설득시킬 것 같습니다. 그리고 그 이후에는 만약에 또 다른 리스크가 높지 않은 업무가 부여된다면 그때 새로운 방법으로 시도해보자고 설득을 할 것 같습니다.

----------------------------------------------------------------------

질문 3:
우선 저는 저의 잘못을 인정하는 것이 가장 중요하고 가장 첫번째 단계라고 생각합니다. 제가 어떤 부분을 잘못했고 어떤 부분에 대해서 명확하게 잘못 판단하였는지를 정리를 하고 반성을 하여서 기존에 반대하던 팀원들에게 설명을 할 것 같습니다. 그래서 그것을 바탕으로 제가 앞으로 어떻게 나아갈 것인지에 대해서 명확하게 말을 해주면서 저의 목표를 다시금 그들이 이해할 수 있도록 설명을 해 줄 것 같습니다.

----------------------------------------------------------------------

질문 4:
우선 저는 그 팀원이 어떤 생각을 가지고 있는지 단순한 불만 수준에서 그치도록 두는 것이 아니라 명확하게 어떠한 측면에서 혹은 어떠한 문제 상황에서 그렇게 느꼈는지를 설명하도록 이끌 것 같습니다. 예를 들어서 구체적으로 프로젝트명을 들면서 본인이 어떻게 나아갔으면 좋았을 것인지에 대해서 설명을 하도록 하여 우선 첫번째로는 해당 불만을 토로하는 팀원이 조금 더 반성을 할 수 있도록 이끌 것 같습니다. 그리고 이후에 해당 팀원의 이야기를 들은 다른 팀원들은 어떻게 생각하는지 개별적으로 이야기를 들어보면서 제가 그 중간에서 조정자 역할을 할 것 같습니다.

----------------------------------------------------------------------

질문 5:
저는 팀 그리고 팀의 관계 해보기 위해서 가장 중요한 것이 소통 그리고 커뮤니케이션이라고 생각합니다. 따라서 해당 앞에서 모든 사람들이 다 앞에 있는 회의에서는 다 본인이 어떻게 생각하는지 구체적으로 말을 못했을 수도 있으므로 개인적으로 다가가서 개인적으로 어떤 생각을 가지고 있는지를 구체적으로 물어보며 조정자 역할을 하면 팀의 소통을 더욱 원활하게 이루어질 수 있도록 하는 역할을 수행할 것 같습니다.

----------------------------------------------------------------------

질문 6:
저는 마케팅의 팀원들에게 단기적으로 성과를 올리는 것보다 장기적으로 브랜드의 가치를 올리고 장기적으로 브랜드의 그런 매출을 올리는 것이 더욱 중요함을 우선 설명해 줄 것 같습니다. 그리고 그러기 위해서는 고객과의 신뢰가 무엇보다도 가장 중요한 가치이며 이렇게 신뢰를 잃어서 성공하지 못한 기업들의 사례를 보여주며 마케팅 팀원의 그런 설득을 시킬 것 같습니다.

----------------------------------------------------------------------

질문 7:
저는 제가 생각하는 가장 중요한 고객가의 가치는 신뢰라고 생각을 합니다. 아무리 저희의 제품이 굉장히 좋더라도 혹은 마케팅 역량이 뛰어나더라도 고객가의 신뢰가 있지 않으면 브랜드의 인지도는 떨어질 수 밖에 없고 브랜드의 가치 또한 내려갈 수 밖에 없게 됩니다. 따라서 단기적인 성과가 증가하지 않고 첨체되는 것처럼 보여도 신뢰를 꾸준히 쌓아가는 것이 더욱 중요하다는 것을 저는 여전히 고수하기 때문에 이러한 측면에서 조금 더 고객들이 원하는 고객들의 마음을 움직일 수 있는 문구를 생각을 해내며 과장 광고보다는 이러한 신뢰적인 고객들의 신뢰를 얻을 수 있는 문구를 활용하자고 이끌 것 같습니다.
